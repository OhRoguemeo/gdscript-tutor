# Starter Godot 4 projects

Version 1 of the tutor does not run GDScript in the browser and does not use a server-side code sandbox.

When you reach **Signals practice** (Module 6) or the **Capstone mini-game** (Module 7), you will download a starter Godot 4 project as a `.zip` file, unzip it, and open it in the Godot 4 editor on your computer.

The zip files will be added here in a later pass:

- `06-signals-practice.zip` — practice declaring signals, sending them with `emit()`, and listening with `connect()` (flashlight, fear changed, player spotted).
- `07-capstone-mini-game.zip` — a short horror vignette that uses variables, types, conditionals, loops, functions, and signals together.

Until those zips are ready, this folder is a placeholder so the project structure is in place.
